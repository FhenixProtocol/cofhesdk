Share metadata: a SNAPSHOT share can carry one label per handle saying where the value came from — a stored value (a view call at a block) or an event value (one log: block, transaction, log index, event selector). `client.acp.createSharing({ ..., labels })` keeps them on the sharing ACP as `metadata`, so `shareOnChain(acp)` posts them and `export()` writes them into the JSON (`SharedACP.metadata`, optional); `importShared` and `importFromChain` keep them on the recipient ACP. `client.acp.shareOnChain(acp, { labels })` posts other labels instead; `client.acp.verifyShareLabels(share, { verify: 'all' | 'events' | 'none' })` checks them against the chain, for a share read from the registry or an imported ACP; `describeShareMetadata(blob, handles, abis)` turns them into function and event names and params. Also exported from `@cofhe/sdk/acps`: `encodeShareMetadata`, `decodeShareMetadata`, `verifyShareLabel(s)`, `describeShareLabels`, `eventLabelOfLog`, `confidentialBalanceLabel`.
